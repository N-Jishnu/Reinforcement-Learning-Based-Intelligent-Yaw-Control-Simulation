# Shared UI primitives

This project uses Streamlit's built-in controls rather than custom frontend components.

- `streamlit` primitives: `st.title`, `st.header`, `st.tabs`, `st.columns`, `st.metric`, `st.dataframe`, `st.pyplot`, `st.selectbox`, `st.slider`, `st.number_input`, and `st.text_input`.
- The dashboard is a single-page application; no reusable custom UI component source files exist.
